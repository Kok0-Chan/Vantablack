
# 🖤 Vantablack

**Vantablack** is a chaotic meme generator for true shitposters. It absorbs your sanity and outputs pure, unfiltered visual nonsense.

No logic. No context. Just absolute absurd.

## 💀 What is this?

Vantablack is a lightweight Python script that takes a random image, slaps some degenerate text on it, and saves the result. It's designed for people who understand that real memes don't need context — only vibes.

## ⚙️ Features

*   **Pixel-Perfect Overlays:** Text rendering with surgical precision.
*   **Zero Logic:** Random phrases on random images. That's it.
*   **Dark Aesthetic:** Built for creators who prefer their tools as sharp as obsidian.
*   **Pure Python:** Powered by the `Pillow` library. Fully customizable for your specific brand of nonsense.

## 🚀 How to Use

1.  **Install dependencies:**
    ```bash
    pip install Pillow
    ```

2.  **Prepare your files:**
    *   Put your images (`.jpg` or `.png`) in the same folder as the script.
    *   Add a font file (e.g., `arial.ttf`) if you want custom text.
    *   Edit the `memes` list in `main.py` with your own phrases.

3.  **Run the generator:**
    ```bash
    python main.py
    ```

4.  **Check the output:**
    The script will create a new file like `meme_output.jpg` in the same folder.
